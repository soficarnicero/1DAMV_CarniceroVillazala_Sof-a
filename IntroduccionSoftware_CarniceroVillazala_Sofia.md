# Ejercicio 1
## ¿Qué es un programa informático?
### Es una serie de instrucciones en un lenguaje de programación que una computadora interpreta para realizar una tarea específica o resolver un problema.

## Diferencia entre código fuente, código objeto y código ejecutable.
| Nombre | Descripción |
| --- | --- |
| código fuente | es un conjunto de líneas  de texto con los pasos que debe seguir un ordenador. |
| código objeto | El resultado de traducir el código fuente a un formato binario o intermedio. |
| código ejecutable | archivo binario con instrucciones directas en lenguaje de maquina que un ordenador puede procesar |
